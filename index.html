Para que serve?

A NOVVO é um ponto de partida para quem vai montar um site do zero. Em vez de dezenas de abas abertas, você encontra poucos sites bons, separados por tarefa: buscar inspiração de layout, achar imagens grátis, criar ilustrações e vídeos com IA e montar mockups.

Cada card mostra o custo e se a ferramenta se conecta a IAs (o tal MCP). Ficou alguma palavra estranha? Veja o glossário.

Glossário

As palavras que aparecem aqui no site, explicadas sem complicação.

10 termos
MCP
Conector que permite a uma IA, como o Claude, usar uma ferramenta por você: buscar imagens, abrir arquivos, editar um design. Nos cards, “Oficial” foi feito pela própria empresa, “De terceiros” foi feito pela comunidade e “Sem MCP oficial” ainda não existe.
Agentes de IA
IAs que não só respondem, mas executam tarefas por você, usando ferramentas para buscar, criar e editar. É por isso que cada card mostra se o site tem MCP.
UI e UX
UI é a aparência: cores, botões e telas. UX é a experiência de uso: se a pessoa acha o que procura com facilidade.
Layout
O jeito como os elementos ficam distribuídos na página. Os sites de Inspiração mostram layouts reais.
Hero
A primeira seção do site, a que aparece antes de rolar a página, com título, frase de apoio e botão. Costuma ter uma foto ou um vídeo de fundo.
Mockup
Simulação do design pronto dentro de um celular ou notebook, usada para apresentar o site ao cliente.
Moodboard
Painel de referências visuais (cores, fotos, sites) que define o clima do projeto. O Pinterest é muito usado para isso.
Template e kit
Modelos prontos para editar, como os kits de UI da comunidade do Figma.
Shots
Como o Dribbble chama as prévias de design que os designers publicam.
Custo
“Grátis” não cobra nada. “Assinatura” pede um plano pago. “Crédito” cobra por uso, como em gerar imagens e vídeos com IA.
